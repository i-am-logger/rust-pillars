# Sources

Each file here is a primary source a note or a skill cites, committed at the
commit it was read from and pinned in [MANIFEST.toml](MANIFEST.toml) by
sha256 (`cargo xtask sources` re-hashes every one). Committing a file is
distributing it, so each entry names its license; all are permissive
(MIT or MIT OR Apache-2.0).

Effective Rust (CC BY-NC-ND) is cited by name and never committed or
paraphrased here.
